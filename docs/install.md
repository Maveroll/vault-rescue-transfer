# Установка на ноутбук

Версия 0.3.0: Obsidian 1.14.4 или новее, только компьютер. Node.js на ноутбуке-отправителе не нужен. Для приёмника на другом компьютере нужен Node.js 22+ и настроенный ретранслятор.

## Через BRAT внутри Obsidian

1. В Obsidian откройте **Настройки → Сторонние плагины → Обзор**.
2. Найдите **BRAT**, установите и включите его.
3. Откройте настройки BRAT и выберите **Add beta plugin** (добавить плагин).
4. Вставьте `https://github.com/Maveroll/vault-rescue-transfer`, выберите версию `0.3.0`, если предлагается выбор, и добавьте плагин.
5. В списке установленных плагинов включите **Vault Rescue Transfer**.

Это установка из GitHub через BRAT. Сам Vault Rescue Transfer пока отсутствует в официальном каталоге Obsidian. [Документация BRAT](https://github.com/TfTHacker/obsidian42-brat).

## Вручную из ZIP

1. Откройте [релиз 0.3.0](https://github.com/Maveroll/vault-rescue-transfer/releases/tag/0.3.0).
2. В **Assets** скачайте `vault-rescue-transfer-0.3.0.zip`. Автоматический архив **Source code** содержит исходники, а не готовую установку.
3. Распакуйте папку `vault-rescue-transfer` в `<хранилище>/.obsidian/plugins/`.
4. Проверьте, что `main.js` и `manifest.json` лежат непосредственно в `.obsidian/plugins/vault-rescue-transfer/`, без лишней вложенной папки.
5. Перезапустите Obsidian и включите плагин в настройках сторонних плагинов.

## Первая отправка

На принимающем компьютере запустите приёмник и скопируйте выданный код. На ноутбуке сохраните адрес своего ретранслятора в настройках плагина, нажмите **Отправить снимок** и вставьте код.

Приостановите редактирование и старую синхронизацию, держите оба устройства включёнными до подтверждения проверки. Ключ администратора приёмника не переносится на ноутбук и не нужен BRAT. После обрыва нужен новый запуск приёмника и новый снимок; продолжение старой передачи пока отсутствует.
